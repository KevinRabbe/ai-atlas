# Clean-Sheet Evidence Traceability

Phase-8 requirements must remain traceable to earlier evidence/synthesis. This file records the principal support path without copying implementation names into the specification itself.

## Traceability rule

A future architecture mechanism is justified only if:

`mechanism -> Phase-8 function/invariant -> cross-domain synthesis -> atlas evidence/claims`.

A mechanism justified only by popularity, analogy or current benchmark leadership fails the clean-sheet protocol.

## Core invariants support

### Evidence/belief, temporal applicability, current-belief challengeability

Supported by persistent memory/state benchmarks, partial-observability/state-estimation foundations, and world-model mismatch evidence.

### Authority/data, capability/permission, objective provenance

Supported by agent-security/control evidence and objective-uncertainty research.

### Scoped verification, evaluator independence, assurance scaling

Supported by process/outcome/formal verification, calibration, reward-overoptimization and control-protocol evidence.

### Versioning, recovery and independent self-change acceptance

Supported by self-improving runtime/agent work combined with regression/control evidence; elevated from best practice to architecture invariant because a self-changing system otherwise cannot distinguish improvement from metric/recovery corruption.

### Physical resource bounds

Supported by IO-aware execution, memory management, distributed routing, precision and scaling evidence.

### Lossy-transform disclosure and representation version compatibility

Supported by information/compression foundations, machine-native communication and persistent-state provenance requirements.

## Organizing hypotheses and confidence

### H1 — Adaptive allocation under uncertainty

**Claim:** practical intelligence benefits from allocating computation, information, change, assurance and exploration based on expected future value under uncertain objectives/state and finite resources.

**Support:** recurring independent evidence across Foundations, Systems, Learning, Inference, Persistence, Verification and Self-Improvement.

**Status:** organizing hypothesis, not proven universal law.

**Main falsifier:** matched systems where fixed/uniform allocation consistently equals or beats adaptive allocation across diverse resource/task regimes after accounting for meta-control overhead.

### H2 — Multiple persistence timescales

**Claim:** a hierarchy of reversible and durable state can outperform one mutation lifetime in changing environments.

**Support:** biological plasticity/consolidation, test-time adaptation, external memory, continual learning, transactional self-change.

**Status:** strong design hypothesis; exact hierarchy unresolved.

### H3 — Heterogeneous representations/mechanisms

**Claim:** different information interactions may justify different representations/computational operations rather than one universal block/format.

**Support:** architecture/system hybrids, multimodality, external tools, learned communication, exact interface requirements.

**Status:** plausible but must beat homogeneous alternatives after routing/communication cost.

### H4 — Evidence-linked persistent state

**Claim:** long-lived current state should retain enough links to evidence/provenance to support revision after contradictions/regime change.

**Support:** memory-to-action/state-tracking failures, objective uncertainty, self-improvement rollback/audit needs.

**Status:** strong architecture hypothesis; minimal required provenance remains to quantify.

### H5 — Transactional self-improvement

**Claim:** self-modification should create candidate variants and require independent acceptance/recovery rather than uncontrolled in-place mutation.

**Support:** self-improvement systems with regression gating/populations plus Phase-5 Goodhart/control evidence.

**Status:** high-confidence systems principle for consequential persistent changes.

## Evidence not sufficient to select architecture yet

Phase 8 intentionally leaves unresolved:

- centralized versus distributed metacontrol;
- one versus heterogeneous computational substrates;
- direct-address versus compressed-state balance;
- internal reasoning representation;
- amount of persistent raw evidence;
- learned versus deterministic verification mix;
- exact learning/credit mechanisms;
- developmental/generative versus direct structural specification;
- physical substrate/co-design depth.

These become Phase-9 candidate/experiment dimensions rather than hidden assumptions.
