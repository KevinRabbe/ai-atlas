## First-pass gaps

Before Phase 4 is treated as saturated, expand evidence for:

- memory poisoning, persistent sycophancy and secure revision;
- temporal/causal knowledge graphs and entity resolution;
- active perception and value-of-observation policies;
- multi-agent shared world state and conflicting observations;
- spatial/3D memory and object permanence;
- tactile/proprioceptive grounding;
- long-horizon model uncertainty and safe exploration;
- hierarchical/multi-timescale world models;
- transfer when a decision-sufficient latent model faces a new objective;
- explicit benchmark comparisons of memory retrieval quality versus downstream action quality.
