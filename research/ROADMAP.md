## Phase 10 — Experimental reconstruction

**Active. Three provisional design-principle selections reached on 2026-08-14.**

All six Tier-1 discriminator shapes are implemented: E01, E02, E03, E04, E05 and E09. Promotion/system follow-ups now add E01B, E02B, E04B, E09B and E22.

Current evidence depth:

- control topology: dependency coupling, resource contention and cross-resource substitution;
- cognitive integration: linear and nonlinear/compositional families + training-data shifts + partial sharing;
- representation: flat state and search/backtracking state + bandwidth shift + continuous-score distribution shift + corruption/version tests;
- persistence: fixed staging and hidden-volatility adaptive staging under noisy observations;
- cross-resource metacontrol: learned task/resource quality + current prices across three changing economics regimes.

## Current provisional selections

These are reversible **principles for the current experimental generation**, not concrete products/modules and not a selected Phase-9 architecture family.

### PS-001 / DL-004 — typed hybrid boundary state

Exact identity/control/provenance fields remain exact; tolerant numerical state may use compact approximate/learned channels; version and integrity semantics remain explicit at changing boundaries; human-readable audit is generated when needed rather than being mandatory hot-path state.

### PS-002 / DL-009 — staged adaptive persistence

New evidence normally enters reversible/tentative state before globally durable mutation. Persistence thresholds/timescales may adapt to estimated environmental stability rather than being one global constant.

### PS-003 / DL-001 — coupling-scoped coordination

Keep execution/local decisions local while coupling is local. Introduce resource/domain/global arbitration only at the scope where dependencies or shared scarcity actually couple decisions. The selected object is the scope rule, not a permanent centralized or distributed topology.

## Highest-value unresolved decisions

- **DL-002 cognitive integration:** two task families favor adaptive degree of sharing, but partial sharing still has unmatched realized compute; compute-matched conditional sharing is required.
- **DL-003 evidence vs compressed current state:** E03 has baseline evidence but needs promotion-quality second-family/resource tests.
- **DL-005 inference budget:** E05 has baseline adaptive-compute evidence but needs OOD cost shifts and a second problem family.
- **DL-022 cross-resource metacontrol:** E22 shows adaptive substitution (~0.032 post-shift regret vs ~0.505 for frozen economics) but requires a second family with shared capacity/quality drift before selection.

## Near-term order

PS-001/002/003 are now such selections; the phase is **not complete** because core state, compute-budget and integration decisions remain open.
