# Contradictions Register

Contradictions are research targets, not cleanup problems.

| ID | Question | Finding A | Finding B | Possible moderator | Decisive experiment |
|---|---|---|---|---|---|
| X-001 | Does more recursive depth improve reasoning? | recursion can extend effective context/decomposition | additional depth can add coordination cost and error propagation | task decomposability, child quality, context policy, stopping rule | factorial study across depth, branching, task structure and fixed compute |
| X-002 | Should knowledge be parametric or external? | weights give fast integrated pattern completion | external stores are updateable, attributable and capacity-flexible | access frequency, volatility, retrieval precision, latency | equal-cost comparisons with controlled knowledge change rate |
| X-003 | Is explicit textual reasoning beneficial? | intermediate reasoning/search often improves hard-task accuracy | text can be verbose, unfaithful, costly and constrain representation | task, supervision, hidden-state capability, verifier availability | compare textual, latent, executable and hybrid deliberation under fixed compute |
| X-004 | Is a larger general model better than specialists? | scale improves broad competence | conditional/specialist routing can reduce active compute | routing quality, task diversity, transfer needs | equal-total-cost generalist vs heterogeneous routed system |
| X-005 | Is representation compression a cause of generalization? | information-bottleneck/relevance views make selective compression theoretically useful | deep networks can generalize without the claimed compression phase and some measured compression reflects representation/estimator effects | stochastic vs deterministic codes, task relevance, nonlinearity, MI estimator, objective | intervene on task-relevant/irrelevant retained information while holding fit, architecture and compute constant |
| X-006 | Does interpolation imply poor generalization? | classical capacity intuition associates exact fitting of noisy data with overfit | double-descent/benign-overfitting results show interpolating solutions can generalize optimally in some regimes | solution norm, optimizer bias, data spectrum/noise, sample-to-capacity ratio | equal-function-class study controlling selected solution and data covariance across interpolation threshold |

When a contradiction is resolved, preserve the original entry and add the moderator/conditions that reconcile it. Do not delete history merely because a cleaner story becomes available.
