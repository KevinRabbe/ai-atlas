# Causality, State Estimation and Control

## Required function

Choose actions that change future states, rather than merely predict observations generated by an unchanged process.

## Prediction is not intervention

A predictive model estimates what tends to happen under the data-generating process. An acting system needs to estimate what would happen **if it changes that process**. Those questions coincide only under additional assumptions. Correlation can be sufficient for prediction while remaining misleading for intervention.

This distinction becomes increasingly important as an AI gains tools or autonomous action: a system can be an excellent passive predictor yet systematically choose bad interventions if it treats correlational regularities as causal effects.

## State is a computational abstraction

Control and filtering research show why a system does not necessarily need the full raw history at every step. It can maintain a state/belief representation sufficient for predicting relevant future dynamics, then update that state with new evidence. Whether a compact sufficient state exists depends on the environment and objective.

This is a useful abstraction for later memory and agent work: the important question is not “how much context can we keep?” but “what state must persist to support future decisions, and what uncertainty about that state remains?”

## Model, estimation and policy are separable functions

At minimum, an acting system faces distinct questions:

1. What state am I probably in?
2. How will the world change without/with an action?
3. What outcomes matter?
4. Which action has the best expected consequences under uncertainty?
5. Is gathering more information worth delaying action?

A single learned network may implement several of these jointly, but clean-sheet synthesis should not assume they are the same computational function.

## Clean-sheet restatement

The system needs mechanisms for **maintaining decision-relevant state, predicting action-conditioned consequences, distinguishing observation from intervention, and selecting actions while valuing information and future effects**.

## Open questions

- When can causal structure be learned from passive data versus requiring intervention?
- How should causal/world-model uncertainty affect irreversible actions?
- When is an explicit latent state useful versus direct history-conditioned control?
- Can a system learn abstractions whose state variables remain stable across environment changes?
- How should long-horizon planning handle model error that compounds with rollout depth?

## Discriminating experiments

Create environments where observational correlations deliberately disagree with intervention effects. Compare passive prediction quality against action quality, and measure how quickly interaction lets systems repair the causal model.

## Failure modes

Correlation-to-causation transfer; stale state estimates; overconfident long rollouts; hidden confounding; policy exploiting simulator/model errors; exploration that is informative but unsafe or irreversible.
