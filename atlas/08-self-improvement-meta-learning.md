# Self-Improvement & Meta-Learning

## Required function

Convert experience and evaluation into durable improvements while controlling regression, overfitting and feedback-loop failure.

## Candidate improvement substrates

Active state; retrieval/context policy; episodic/semantic memory; executable skills; prompts/instructions; tool/interface design; routing/scheduling; harness code; training data; reward/evaluator models; task-model weights; architecture.

## Timescale hypothesis

Cheap/reversible substrates should generally be tested before expensive/irreversible ones, but this is a hypothesis to validate rather than a fixed law.

## Early evidence anchors

Reflexion demonstrates improvement from retained linguistic feedback without weight updates. Meta-Harness searches over harness code. Self-Harness uses weakness mining, proposal generation and regression validation. AlphaEvolve combines proposal generation, automated evaluation and evolutionary selection to discover deployable algorithms. SIA explicitly explores joint harness and weight updates.

## Clean-sheet questions

- What determines the correct substrate for a learned improvement?
- When should repeated episodic patterns become procedures or weights?
- How can improvements be tested for broad regressions before persistence?
- How do we prevent optimization from exploiting evaluators?
- Can the system maintain competing hypotheses/architectures instead of prematurely converging?
