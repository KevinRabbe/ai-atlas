# Atlas Index

The taxonomy is organized around computational functions rather than current products.

| ID | Domain | Central question |
|---|---|---|
| 00 | Foundations | What principles constrain learning, representation, computation and intelligence? |
| 01 | Model architectures | What neural/computational substrate should transform information? |
| 02 | Learning & training | How should capability be acquired and updated? |
| 03 | Reasoning, search & planning | How should compute be allocated to solve nontrivial problems? |
| 04 | Memory, context & knowledge | What should be stored, where, for how long, and how retrieved? |
| 05 | Tools, agents & harnesses | How should models interact with environments and external computation? |
| 06 | World models & simulation | How should consequences, dynamics and counterfactuals be predicted? |
| 07 | Verification & evaluation | How should candidate outputs/actions be judged? |
| 08 | Self-improvement & meta-learning | Which parts of the system can improve themselves, and on what timescale? |
| 09 | Representation & communication | What internal/external representations minimize information loss and compute? |
| 10 | Systems, efficiency & hardware | How do memory hierarchy, bandwidth, parallelism and hardware shape viable intelligence? |
| 11 | Multimodality & embodiment | How should heterogeneous sensory/action spaces be integrated? |
| 12 | Safety, control & reliability | How do we constrain behavior and maintain corrigibility under capability growth? |

Cross-cutting dimensions for every domain: capability, efficiency, generalization, uncertainty, adaptivity, interpretability, robustness, scaling, failure modes, and interactions with other mechanisms.
