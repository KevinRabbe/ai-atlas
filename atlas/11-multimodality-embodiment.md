# Multimodality & Embodiment

## Required function

Integrate heterogeneous observations and actions into coherent state, concepts and control without forcing every modality through a lossy human-language bottleneck.

## Modalities to map

Text; images; video; audio; speech; spatial/3D data; proprioception; touch; time series; software/UI state; structured data; sensors; motor/action spaces.

## Research dimensions

Joint versus modality-specific encoders; cross-modal alignment; shared latent spaces; temporal grounding; active perception; sensor fusion; action-conditioned representation; embodiment; spatial memory; object permanence; multimodal world models; tool-mediated perception.

## Clean-sheet questions

- Which representations should be shared across modalities and which should remain specialized?
- Is language a useful semantic hub or an unnecessary compression bottleneck for some modality pairs?
- How should temporal/spatial state persist beyond a context window?
- When should perception be active—choosing what to observe next—rather than passive?
- How should uncertainty from different sensors be fused?
- What capabilities require physical embodiment versus simulated or digital interaction?
